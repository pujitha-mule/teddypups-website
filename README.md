# TeddyPups multi-page clone

Open `index.html` with Live Server in VS Code. The six pages share `style.css` and `script.js`.

Pages: index.html, puppies.html, happy-families.html, how-it-works.html, faq.html, contact.html and gone-home.html.

The puppy photos and logo are loaded from the supplied reference website. If those remote assets become unavailable, download permitted assets into a local `assets/` folder and update the paths. The contact form opens WhatsApp with a prefilled message; it does not store submissions.

The local/imported filter does not assign unsupported origins to individual puppies. The Korean filter is based on the puppy names shown in the supplied reference.
